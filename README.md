# 书目索引

从英文书名中自动提取关键词，建立「关键词 → 书号」索引，并支持按词查询。

做法来自严蔚敏、吴伟民《数据结构》（C 语言版）第 4 章「建立词索引表」：读入书目和常用词表，从书名里切出单词，丢掉常用词，得到按字典序排列的词索引。本项目在此之上补上逐本增删改、可编辑的常用词表，以及把书目保存到文件、下次启动时重建索引。

第一版是 C 语言命令行程序。索引只用已经学过的结构：带头结点的有序单链表，以及逐字符切词。

## 数据结构

三张表都是带头结点的单链表。查找用顺序比较，新结点插到第一个比它大的结点前面，和多项式按指数有序插入相同。


| 表    | 结点里有什么         | 顺序                |
| ---- | -------------- | ----------------- |
| 书目表  | 书号、原书名、规范化书名、抽出的关键词 | 书号从小到大；新书加在表尾     |
| 常用词表 | 一个小写词          | 字典序               |
| 词索引表 | 小写关键词，以及一条书号链表 | 关键词字典序；书号从小到大且不重复 |


删除一本书，或因改名冲突而删掉它时，用结点里保存的关键词到对应书号链表里摘掉该书号。某词的书号链表空了，就把这个词从索引表里删掉。

添加、修改或因冲突删除一本书时，要么整步完成，要么书目表和索引表都保持原样。

## 书目

- 书号由程序分配，从 1 开始，取当前最大书号加 1。删除后不回收。
- 书结点保存书号、原书名、规范化书名和抽出的关键词。原书名保持用户输入的大小写。显示和写文件时都用原书名。
- 规范化书名只用于判断是不是同一本书：去掉首尾空白，把连续空白收成一个空格，再全部转成小写。`Data Structures` 与 `data structures` 的规范化书名都是 `data structures`。
- 规范化书名不删除字符。连字符、数字、标点和其他非英文字母仍然使整本书名非法，程序拒绝录入，已有索引不改。书名通过合法性检查后，切词和提取关键词都使用规范化书名。它已经是小写，连续空白也收成了一个空格，切出的词与扫描原书名再逐个转小写相同。
- 一个书名只对应一个书号。插入前用新书名的规范化形式查询；已存在则不分配书号，也不改索引。
- 修改时，新书名的规范化形式若与另一本书相同，删掉正在修改的这一本，包括它在索引中的书号。另一本书保持原书号和原书名。正在修改的这本书不再存在。
- 新书名的规范化形式若与自己相同，只更新原书名，书号和关键词不变。
- 书名去掉首尾空白后不能为空，最长 200 字节。
- 书名由空格分隔的英文单词组成，单词大小写随意。每个单词只含英文字母。



## 抽词

按空白把书名切成单词。每个词先转成小写，再与常用词表做整词比较，不区分大小写，不用前缀。虚词不进入索引。其余单词作为关键词，统一以小写写入索引。

`DATA` 和 `Data` 建立的关键词都是 `data`。`structures` 和 `structure` 是两个词，不做词干合并。同一书名里同一个词只记一次。

## 常用词

默认常用词：

```text
a an the of and or for to in on with by from into over at as its
```

常用词表放在文件里，可以用命令追加或删除。加入前去掉首尾空白并转成小写；词本身只含英文字母。改过常用词之后，用现有书目把整张索引重建一遍。

## 查询

查询词先走同一套规范化和切词。

- `find data`：精确匹配一个小写关键词，打印书号和原书名。查询词先转成小写。
- `find data structures`：这些词都要出现。对相应的书号链表求交集；链表已按书号排好序，求交和有序表归并是同一类过程。
- 查询词是常用词，或不够资格成为关键词：说明原因。
- 没有书命中：结果为空。



## 文件

磁盘上只保存原书名和常用词。程序启动时读入这两份文件，由原书名重新计算规范化书名、关键词和索引。文件不存在时，从空书目和上面的默认常用词开始。

`books.txt` 每行一本书，书号和书名之间用制表符分隔：

```text
1	The Design and Analysis of Computer Algorithms
2	Fundamentals of Data Structures
```

`stopwords.txt` 每行一个常用词。空行以及以 `#` 开头的行忽略。

## 命令

`add` 和 `edit` 后面整行都是书名。


| 命令                | 作用                                    |
| ----------------- | ------------------------------------- |
| `add <书名>`        | 书名尚不存在时分配新书号，抽词并写入索引；已存在则不改数据，并提示已有书号 |
| `edit <书号> <书名>`  | 新书名无人使用时保持书号并重新抽词；与另一本书重名时删掉当前这本书 |
| `del <书号>`        | 删除这本书，并把它从索引中摘掉                       |
| `list`            | 列出书号和原书名                              |
| `index`           | 按字典序列出关键词及其书号                         |
| `find <词> [词...]` | 按一个或多个关键词查询                           |
| `stop add <词>`    | 加入常用词并重建索引                            |
| `stop del <词>`    | 删除常用词并重建索引                            |
| `stop list`       | 列出常用词                                 |
| `save`            | 把书目和常用词写回文件                           |
| `load`            | 从文件重新读入并重建索引                          |
| `help`            | 列出命令                                  |
| `quit`            | 退出                                    |


未知命令、不存在的书号、非法书名都给出说明，并且不改已有数据。插入时书名已存在，同样不改数据，并提示已有书号。改名与另一本书重名时，删掉当前这本书，并提示被保留的那本书的书号。

## 示例

常用词含 `the`、`of`、`and`、`to`。三本书是：

1. `The Design and Analysis of Computer Algorithms`
2. `Fundamentals of Data Structures`
3. `Introduction to Data Structures`

索引为：

```text
algorithms: 1
analysis: 1
computer: 1
data: 2 3
design: 1
fundamentals: 2
introduction: 3
structures: 2 3
```

`find data structures` 得到书号 2 和 3。`find the` 会说明 `the` 是常用词。

## 第一版不做的事

中文分词、前缀或模糊查询、作者、出版社、ISBN，以及树和哈希。这些都不进入第一版。
